# Bundled font

`NotoSansCJK-Regular.ttc` is the fixed CJK font used by the reference project and render tests.

- Upstream: Noto CJK (`https://github.com/notofonts/noto-cjk`)
- Local source package: Ubuntu `fonts-noto-cjk 1:20240730+repack1-1build1`
- Copyright: 2010–2012 Google Corporation
- License: SIL Open Font License 1.1; see `OFL-1.1.txt`
- SHA-256: `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`

Keep the font bytes fixed when updating golden images. A font update requires a new hash, license review, and explicit regeneration of every affected text golden.
