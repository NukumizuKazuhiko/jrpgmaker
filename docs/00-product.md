# 产品定义

> 状态：当前有效（登记于 [README.md](README.md)）。修订本文件前必须经用户确认。

## 一句话定位

为 JRPG 服务、可复用且可扩展的 3D 游戏运行框架：引擎提供探索、事件、对话、日期、场景和呈现基础合同；项目用纯数据定义内容，并通过插件自行选择战斗规则与渲染风格。

## 背景与要解决的问题

通用引擎通常只提供底层场景、输入和渲染能力，JRPG 项目仍需重复搭建事件脚本、对话、日期日程、地图触发、遇敌与内容校验。jrpgmaker 把这些跨项目稳定的 JRPG 工作流做成引擎合同，同时把差异最大的战斗规则和渲染风格留给插件，避免引擎把项目锁死在某一种玩法或画风中。

## 目标用户

1. 首要用户：项目所有者本人（用此引擎制作自己的 JRPG）。
2. 次要用户：希望通过数据文件和源码级插件组装自己项目的 JRPG 开发者。

## 产品形态

| 维度 | 引擎保证 | 项目或插件自主定义 |
|---|---|---|
| 世界 | 3D 场景、角色移动、碰撞、寻路、第三人称/固定机位相机合同 | 地图布局、导航、碰撞体、相机区域、遇敌点 |
| 内容 | 版本化数据加载、引用校验、事件与对话运行时 | 日期历法、日程、对话、触发点、剧情、文本与资源 |
| 战斗 | 插件发现、生命周期、输入、结果与 presentation seam | 是否有战斗、战斗类型、角色数值、技能、AI、QTE、结算与战斗 UI 语义 |
| 渲染 | RHI、场景提交、资源生命周期、通用渲染命令 | shader、材质 schema、光照模型、描边、后处理和整体画风 |
| UI | 控件树、布局、CJK 排版和通用绘制数据 | 视觉布局、动效、主题、战斗菜单和项目文案 |
| 平台 | Windows、Linux、macOS 的构建和运行合同 | 项目资源与插件组合 |

## 第一可玩闭环（Vertical Slice 定义）

玩家操控角色在数据驱动的测试地图中移动 → 触发项目声明的扩展流程 → 可选战斗插件接管并返回结构化结果 → 项目事件根据结果继续 → 返回探索 → 存档退出 → 读档后状态一致。

参考项目使用一个可删除的战斗示例插件演示“遇敌→插件运行→结果事件→返回探索”。示例插件的角色、技能、数值、QTE 和奖励数据均属于插件或参考项目，不属于引擎固定 schema。

全程内容（日期、地图、对话、触发、插件选择、插件数据、材质实例和演出）由版本化数据文件组装，零硬编码剧情。

时点拆分（与 [02-milestones.md](02-milestones.md) 对齐）：

- **插件闭环（P5 达成）**：移动→遇敌→战斗插件运行→结果事件→返回探索；替换插件不修改 `engine/`。
- **渲染风格闭环（P6 达成）**：替换渲染风格插件不修改 RHI 后端或项目业务数据。
- **完整第一可玩闭环（P7 达成）**：加入自定义日期/日程、版本化存档与读档一致性。

## 边界 @@BOUNDARY@@

### 做（主线）

- 数据驱动的 JRPG 运行框架：探索、事件、对话、日期/日程、地图触发和项目装配。
- 通用源码级插件宿主；战斗规则和渲染风格分别经稳定 seam 接入。
- 项目可自定义日期、对话、触发点、地图、输入映射、材质实例及所选插件。
- Windows(D3D12) + Linux(Vulkan) + macOS(Vulkan/MoltenVK)。
- JSON 数据文件 + schema/引用校验 CLI；GUI 编辑器远期另行立项。

### 不做（非目标）

- 通用全类型引擎、网络多人和开放世界流式加载。
- 在 `engine/domain` 内内置任何特权战斗规则、角色数值表、技能、buff、伤害公式或战斗 UI 语义。
- 在 `engine/render` 内绑定某一种固定画风、固定材质模型或项目级 shader 组合。
- P5/P6 承诺跨编译器稳定的热加载 DLL ABI；第一阶段插件为源码级、构建期注册。
- 主机、移动端首发。
- 第一阶段的 GUI 编辑器。

### 已否定方向（防止回潮）

- 已否定“Persona 式视觉形态是引擎固定目标”；画风由渲染风格插件和项目资产决定。
- 已否定“回合制/QTE/ACT 合同由引擎核心预设”；这些均由战斗插件自主定义，引擎只拥有插件宿主 seam。
- 已否定“actor/skill/buff/伤害公式是引擎统一数据 schema”；其 schema 与 validator 由战斗插件拥有。

## 成功标准（全部可验证）

1. **构建**：三个目标平台从源码一键构建并通过全部测试（CI 绿灯）。
2. **数据自主**：参考项目仅通过数据文件修改日期、对话、触发点、地图、输入映射与材质实例，不修改引擎源码。
3. **战斗可插拔**：两个真实战斗插件通过同一宿主合同运行；切换项目清单中的插件 ID 即可替换规则，`engine/` 零改动。
4. **风格可插拔**：至少两个渲染风格插件通过同一 render seam 运行；替换风格不修改 RHI 后端和 domain 业务状态。
5. **竖切**：30 分钟可玩参考项目达成探索→项目事件→可选插件→返回探索→存读档一致性，剧情和项目规则零硬编码。
6. **渲染一致性**：同一套 RHI 合同测试在 D3D12 与 Vulkan 双后端绿灯。
7. **CJK**：日文禁则换行、中文排版用例通过 golden image 校验。
